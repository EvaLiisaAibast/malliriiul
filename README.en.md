# Malliriiul — the room and the template gallery

A single static web page that looks like a small 1920s living room. Everything in the
room can be touched: the clock ticks, the gramophone plays, the piano can be played, the
corkboard can be drawn on, the cabinet can be opened and hidden objects can be found
behind it. In the middle of the room stands a bookshelf whose volumes are actually the
**ten website templates** of a school workshop — clicking a volume opens a live preview
and a ZIP download.

The whole site is **plain HTML + CSS + JavaScript**: no build step, no Node, no database,
no framework. Just files you can put on any static server (GitHub Pages, Nginx on a
Raspberry Pi, `python3 -m http.server`).

│   │   ├── klaver.png
│   │   ├── kleit.png
│   │   ├── postkaardid/
│   │   └── valjaloiked/  ← 13 period cut-outs (1920s images)
│   ├── sein/  riistad/  esemed/  taust/
│   ├── loomad/  linnud/  putukad/  taimed/  loodus/  autod/  soidukid/  inimesed-ja-kohad/
├── mallid/               ← 10 website templates, one folder each (index.html + stiil.css + pildid/)
├── zip/                  ← ready-made ZIP files for template downloads

`index.html` is the only file the room needs. `mallid/`, `zip/` and `pildid/` are local
assets; `skriptid/` is only for maintenance.

## 2. Running it

**Locally** (recommended, because some features need HTTP):

```powershell
cd INSA_html
python -m http.server 8080
# or
npx serve .
```

Open `http://localhost:8080`.

**Directly as a file** works too (`file:///.../index.html`), but some browsers restrict
iframe previews (`mallid/*/index.html`) in that mode.

**GitHub Pages**: the whole folder is static, all paths are relative and `index.html`
sits in the root — it deploys unchanged. See section 8.

## 3. Dependencies and external services

| Dependency | Where | Purpose | Needs internet? |
| --- | --- | --- | --- |
| GSAP + Draggable | `vendor/` (local) | rotating the gramophone arm and volume knob | no |
| Cinzel Decorative, Cormorant Garamond | Google Fonts (`fonts.googleapis.com`) | typography | **yes** (otherwise system font) |
| Open-Meteo | `api.open-meteo.com` | weather in the window (Tallinn) | yes |
| YouTube / Spotify oEmbed | `youtube.com`, `open.spotify.com` | stream panel titles | yes |
| YouTube / Spotify embed | `youtube.com/embed`, `open.spotify.com/embed` | playing the pasted stream | yes |
| Audio (piano, gramophone, creak) | Web Audio API, synthesised locally | every sound is generated live | no |
| Images | `pildid/` (local) | all graphics | no |

Every external service is optional: without internet the weather shows "Ilm ei ole
saadaval", the fonts fall back to system fonts and the stream panel will not load — but
the room itself works completely.

Image sources are listed in the page's own **Tänud** panel (HUD → Tänud): Jaak Aibast
(photos), The Metropolitan Museum of Art (CC0), Wikimedia Commons (public domain /
CC BY-SA), Livrustkammaren, Pearson Scott Foresman, Wellcome Collection, rawpixel (CC0)
and others.

## 4. Complete list of interactive elements

### 4.1 The room and moving around

| Element | Where | Action |
| --- | --- | --- |
| Room (`#ruum`) | whole screen | drag with the mouse left/right, scroll the wheel or use `←` `→`; pinch-scroll on touch |
| Edge arrows | screen edges | scroll the room one step |
| Door / window | left wing | a real street view is visible; **drag the view** or use the arrow keys |
| Weather | under the window | Open-Meteo data for Tallinn, refreshes automatically |
| Clock | left wing | shows the real time; click opens the **Pomodoro** (25:00, start/pause/reset) |
| Shelf lights (HUD → Riiuli tuled) | under the shelf | 5 tones: gold, pink, mint, lavender, ice blue — changes the lighting of the whole room (`html[data-lamp]`) |
| Books | shelf | click opens the template preview (see 4.6) |
| Drawers | bottom left | click opens a drawer; it contains the photo bank link and a second drawer |
| Wedding dress | right wall | **drag** it around the room (arrow keys nudge 4 px, Shift 16 px); sparkles; position is saved |
| Postcards | wall next to the corkboard | drag them around or nudge with arrow keys; position is saved |
| Squeaky floorboard | right wing, on the floor | click makes a creak **and opens the wall safe panel** |

### 4.2 Tools (toolbar on the cabinet)

The tools hang on the right wall above the cabinet. Pick a tool, then click objects.

| Tool | What it does |
| --- | --- |
| **Hand** | neutral: click objects and open panels |
| **Duster** | drag across the shelf, books and pictures — the dust disappears |
| **Glasses (loupe)** | drag the loupe across the shelf — the small print on book spines becomes readable |
| **Watering can** | click the plants and the pot — plant moisture is restored, a dried plant turns green |
| **Quill** | opens the guestbook for writing (see 5.3) |
| **Moth** | lets the moths out; they circle the room and finally disappear back into the cabinet |
| **Sponge** | cleans drawings and stains off the board and walls |

| Element | Action |

## 5. Puzzles and hidden actions (step by step)

### 5.1 The safe and the brass key

1. Look at the **clock** or the **shelf lights** — the hint is "clock 03:33 or ice-blue light".
2. Click the **squeaky floorboard** (right wing, on the floor) — it opens the wall safe panel.
3. The safe has three dials. Turn them to **3 · 3 · 3** → the safe opens.
4. The safe contains the **brass key**. The key is stored (`malliriiul-voti`) and survives a page reload.

### 5.2 The cabinet: gears → the 1926 drawing

1. With the **brass key**, click the cabinet lock → the door opens.
2. Inside are **three gears**. A click turns one by 90° and its neighbours by 45°.
3. Turn them until all three markers point up (each gear reaches a full circle). If you
   want it faster, press **"Lahenda automaatselt"** (solve automatically).
4. When the mechanism clicks, the **1926 mechanical drawing** appears behind the cabinet.
5. Click the drawing → it is **in hand**; click the corkboard → it is pinned to the board
   (it joins the guest leaves, `malliriiul-joonis`).
6. **The cabinet can only be closed again** once the gears are solved **and** the drawing
   has been taken out. The "Sulge kapp" (close cabinet) button is visible as soon as the
   door is open; if something is still missing, the hint bar says what.

### 5.3 Guestbook and guests

1. Select the **quill** tool (or press the corkboard's `✍`) → the guestbook opens.
2. Write a name and a message; a leaf appears on the corkboard.
3. Leaves can be dragged on the board and deleted with `×`; deleted ones do not come back
   (`malliriiul-korkkust`).

### 5.4 Dust and the loupe

1. Select the **duster** and drag across the shelf, books and pictures — the dust rolls disappear.
2. Select the **glasses** and drag the loupe along the book spines — hidden small print becomes readable.

### 5.5 Plants

Plants have a moisture value (`malliriiul-niiskus`) that drops over time. Select the
**watering can** and click the plant/pot — moisture is restored and a dried plant turns
green again.

### 5.6 Moths

Select **moth** and let them out: they circle the room, bounce off the walls and finally
disappear back into the cabinet ("Koid kadusid kappi tagasi" — the moths went back into
the cabinet).

### 5.7 The dress

The wedding dress hangs on a hanger next to the corkboard as **one piece** (dress +
hanger). It can be dragged anywhere in the room; the position is saved
(`malliriiul-kleit`). The dress sits in a higher z-layer than the shelf panel, so it never
gets stuck behind the bookshelf. The sparkle (22 tiny stars + a sheen band masked by the
dress silhouette) is pure CSS.

### 5.8 Hidden texts

- The clock and the cabinet door carry hints that change with the state.
- The hint bar (HUD, bottom left) narrates what just happened.
- The shelf books have random complaints ("Dust! This shelf is dusty again!") that appear
  while you use the shelf.

## 7. Saved state (localStorage)

Everything the page "remembers" lives in the browser's `localStorage`. The prefix is
`malliriiul-`.

| Key | Contents |
| --- | --- |
| `malliriiul-kapp` | whether the cabinet is open (`true`/`false`) |
| `malliriiul-voti` | whether the brass key is in hand |
| `malliriiul-hammas` | whether the gears are solved |
| `malliriiul-joonis` | drawing state: `peidus` \| `laual` \| `kaes` \| `tahvlil` |
| `malliriiul-kleit` | dress position `[left, bottom]` |
| `malliriiul-korkzoom` | corkboard zoom |
| `malliriiul-korkpinnad` | pin positions |
| `malliriiul-korkkust` | IDs of deleted pins |
| `malliriiul-korkloiked` | cut-outs pinned to the board |
| `malliriiul-korkjoonis` | corkboard drawing (PNG data URL) |
| `malliriiul-kylalised` | guest leaves on the board |
| `malliriiul-kylastus` | visit count |
| `malliriiul-lamp` | shelf light tone |
| `malliriiul-niiskus` | plant moisture |
| `malliriiul-plekid` | stains / dust |
| `malliriiul-postkaardid` | postcard positions |
| `malliriiul-salvestused` | melodies saved on the piano |

**Full reset:** in the browser console

```js
Object.keys(localStorage).filter(k => k.startsWith('malliriiul-')).forEach(k => localStorage.removeItem(k));
location.reload();
```

## 8. GitHub Pages

The site is static and deploys to Pages unchanged: relative paths only (not a single path
starting with `/`), `index.html` in the root, all images and JS local. The only things
that need internet are Google Fonts and the weather/stream features (see section 3).

**Note:** the whole folder is published (about 60 MB, including `zip/` and `mallid/`), so
the limits (1 GB repo, 100 MB per file) are not an issue. `skriptid/` (Node) ships along,
but Pages never runs it — it is only for maintenance.

## 9. How to make changes

**A new cut-out for the corkboard**
1. Put the image in `pildid/tuba/valjaloiked/` (preferably 500 px wide, JPEG).
2. In `index.html` find the array `var LOIKED=[` and add a line:
   `{k:'my-id',n:'Name · year',img:'pildid/tuba/valjaloiked/my-image.jpg'},`
3. Done — the button appears on the strip automatically.

**A new gramophone record**
`var PLAADID=[ ... ]` — each row: `[title, source, tone, colour, performer]`.

**A new piano piece**
`var TUNNID=[ ... ]` — `{nimi, autor, bpm, noodid:'C4 D4 E4 ...'}`.

**Changing the hints**
`RIIS_VIHJED` (tool hints) and the `vihjeEl.textContent=` lines after each action.

**A new template in the gallery**
Add a folder `mallid/<name>/` (`index.html` + `stiil.css` + `pildid/`), then add a row to
the `MALLID` array and pack the ZIP: `node skriptid/pakenda.mjs`.

## 10. Accessibility

- Every important object is focusable (`Tab`) and activatable with `Enter`/`Space`.
- Panels use `aria-expanded`, `aria-controls`, `role="group"`, `aria-label`.
- The hint bar is `aria-live="polite"` — a screen reader announces what happened.
- With `prefers-reduced-motion: reduce`, the moths, rain/snow, the dress sparkle, the
  gramophone rotation and other animations are switched off.
- Audio starts only after a user click (browser autoplay policy).
